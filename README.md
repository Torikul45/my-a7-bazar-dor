# B14-A7-Bazar Dor (বাজার দর)

## Project Description

Bazar Dor is a responsive web application that helps users explore the prices of essential products in Bangladesh. Users can browse product categories, compare current and previous prices, and view product details.

## Technologies Used

* Next.js 16 (App Router)
* React
* TypeScript
* Tailwind CSS
* daisyUI
* Better Auth
* MongoDB
* REST API
* React Hot Toast

## Key Features

1. **Product Price Tracking:** View current prices of essential products.
2. **Price Comparison:** Compare current prices with previous prices.
3. **Price Trend Indicators:** Identify products with increasing or decreasing prices.
4. **Product Categories:** Browse products by category.
5. **Product Sorting:** Sort products by lowest or highest price.
6. **Product Details:** View detailed information about each product.
7. **User Authentication:** Sign up and sign in with Better Auth.
8. **Social Login:** Google and GitHub login options, subject to configuration.
9. **User Profile:** View and update profile information.
10. **Responsive Design:** Supports mobile, tablet, and desktop screens.
11. **Custom 404 Page:** Shows a custom page for unavailable routes.

## Getting Started

### Prerequisites

* Node.js
* npm
* MongoDB connection for authentication

### Installation

1. Clone the repository after it is available on GitHub:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project directory:

   ```bash
   cd my-a7-bazar-dor
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure the required environment variables in `.env.local`.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open http://localhost:3000 in your browser.

## Environment Variables

Configure the API URL, Better Auth URL, Better Auth secret, and MongoDB connection string in your local environment file as required.

**Security:** Never upload `.env` or `.env.local` files containing secrets to GitHub.
